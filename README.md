# 戦車道RTS（プロトタイプ）

ガールズ&パンツァーの非公式二次創作の、見下ろし型戦車戦RTSです。プレイヤーは隊長として戦車隊を指揮します。World of Tanks の装甲角度・跳弾・索敵・隠蔽の考え方を2Dに落とし込んでいます。

ブラウザだけで動きます（ビルド不要、外部ライブラリなし）。車輌・乗員の数値はすべて仮値です。

## 起動

ES Modules と JSON を読み込むため、`index.html` を直接ダブルクリックでは開けません。ローカルサーバーから開いてください。

```sh
# どれか1つ
npx http-server -p 8080 -c-1 .
python -m http.server 8080
```

- ゲーム： http://localhost:8080/index.html
- エディタ： http://localhost:8080/editor.html

GitHub Pages（Settings → Pages → main ブランチのルート）でもそのまま公開できます。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 左クリック／左ドラッグ | 自軍車輌を選択（Shiftで追加） |
| 右クリック | 移動。敵を右クリックで集中射撃 |
| 右ドラッグ | 移動先＋到着後の車体の向き |
| Ctrl＋右クリック | 後退（正面を向けたまま後進） |
| Q／E | 車体を左右に15°振る |
| S／H／Z | 停止／射撃モード（自由→待ち伏せ→禁止）／分隊任務に戻す |
| 数字キー | 分隊を選択（2回押しでカメラ移動）。Ctrl＋数字で選択車輌を分隊へ編入 |
| R T G B F X | 分隊への大まかな指示：偵察・攻撃・防御・後退・追従・手動 |
| スペース | 一時停止 |
| 矢印キー／中ボタンドラッグ／ホイール | カメラ |

### 分隊への大まかな指示

部隊を複数の場所に分けたとき、全車を細かく操作しなくて済むように、分隊単位で任務を出せます。任務を出した後の位置取り・向き・射撃の判断は分隊AIが行います。

| 任務 | 分隊AIの動き |
| --- | --- |
| 偵察 | 横隊で前進。敵を見つけたら停止して隠れ、近づかれるか撃たれるまで撃たない。被弾した車は下がる |
| 攻撃 | 楔形で前進し、射程に入った敵と交戦。分隊で目標を揃えて集中射撃 |
| 防御 | 目標地点付近の茂みの15m後ろ・遮蔽地形の陰に散開して待ち伏せ |
| 後退 | 敵に正面を向けたまま後進で下がる |
| 追従 | 指定した分隊の後ろに縦隊で付いていく |
| 手動 | 分隊AIを止める |

任務を選んだあと、地図を右クリック（右ドラッグで敵の方向も指定）します。個別命令を出した車輌は分隊任務から外れ、Zで戻ります。

### 一時停止

難易度によって既定が変わり、タイトル画面で個別に切り替えられます。

| 難易度 | 一時停止 |
| --- | --- |
| イージー／ノーマル | 自由 |
| ハード | 1試合3回まで |
| ベリーハード | なし |

## エディタ（editor.html）

戦車・キャラ・スキル・セリフ・編成をフォームで編集できます。

- **戦車**：装甲6面、砲・弾種、機動、隠蔽、乗員の席（兼任）、画像。プレビューで車体の振り角と撃ってくる弾を選ぶと、前面・側面の実効装甲と跳弾／貫通の判定を試算します
- **キャラ**：熟練度、スキル、顔グラ（表情5種）。画像がなければ色付きの円＋略字で表示
- **スキル**：層（個人／役職／車長／分隊長／隊長／アクティブ）と効果
- **セリフ**：キャラ×イベント。音声ファイルのパスも書けます（ゲーム設定でボイスを有効にした時のみ再生）
- **編成・シナリオ**：両チームの分隊、車輌、乗員の割り当て、隊長車・フラッグ車
- **JSON直接編集**：マップなどフォームにないデータ

保存先は3通りです。

1. **ブラウザに保存**：このブラウザのゲームにすぐ反映されます（タイトル画面に「エディタで保存したデータを使用中」と出ます）
2. **data フォルダに保存**（Chrome・Edge）：プロジェクトのフォルダを選ぶと `data/*.json` と選んだ画像（`assets/`）を直接書き込みます。コミットすれば全員に反映されます
3. **書き出し**：JSONをダウンロードして、手動で `data/` に置き換えます

## 画像の差し替え

最初は▲（頂点が前方）で描画し、画像を指定すると差し替わります。当たり判定は定義上の車体サイズで行うため、画像を変えてもバランスは変わりません。

- 戦車：`assets/tanks/` に車体・砲塔・撃破後の画像。**前方が上を向くように**描きます。砲塔は回転中心（pivot）を指定
- 顔グラ：`assets/portraits/` に表情ごとの画像

## 構成

```
index.html / editor.html
css/          style.css, editor.css
js/
  main.js       エントリー（タイトル→試合）
  game.js       ゲーム状態と更新、プレイヤー命令
  unit.js       戦車：移動・旋回・照準
  combat.js     射撃判定（跳弾・正規化・実効装甲・貫通）※純粋関数
  spotting.js   索敵・隠蔽・通信網
  squad.js      分隊と大まかな指示（分隊AI）
  ai.js         敵の隊長AI
  stats.js      乗員とスキルから性能を計算
  map.js        地形タイル・経路探索
  render.js     描画（▲／画像）
  ui.js         入力・HUD・カットイン
  editor.js     エディタ
  validate.js   データの整合性チェック
data/         tanks / characters / skills / lines / maps / scenarios (.json)
assets/       tanks / portraits（画像を置く場所）
tests/        node --test で実行
```

## テスト

```sh
npm test
```

射撃計算（跳弾角・3倍口径・正規化・実効装甲・被弾面）と、描画なしで試合を4分回すシミュレーション、同梱データの整合性を確認します。

## 注意

- 非公式の二次創作です。原作の画像・音声・台詞は同梱していません。セリフはオリジナルで書いてください
- 数値はすべて仮値で、史実や原作の設定とは一致しません
